Auditioning with a Screen Reader

Auditioning means hearing a folder, or the area around your editing markers, without touching the mouse.

Hearing a Folder

Choose the folder with Alt+↓, Alt+↑ or D (see Navigating a Project). Moving to a folder makes it the audible one, so there is nothing else to switch. Then:

  • Space plays and stops
  • Shift+Space plays and stops, moving the edit cursor along with the playhead
  • Ctrl+Shift+Space returns to the position where you last stopped

In Mixer Mode, S solos the current mixer track and Shift+S unsolos everything.

Hearing the Area Around Your Markers

Once you have set source and destination markers, each of these selects the right folder, makes it audible and plays a short segment, announcing a message if a marker is missing:

Shortcut Plays
6 / 8 3 seconds from the destination IN / OUT marker
7 / 9 3 seconds from the source IN / OUT marker
Ctrl+6 / Ctrl+8 the 3 seconds up to the destination IN / OUT marker
Ctrl+7 / Ctrl+9 the 3 seconds up to the source IN / OUT marker
Alt+6 or Alt+8 from the destination IN to the destination OUT marker
Alt+7 or Alt+9 from the source IN to the source OUT marker

Starting a new audition stops any audition still playing. Use Ctrl+, and Ctrl+. to nudge a marker after hearing it, then audition again.

Auditioning a Crossfade

In crossfade mode (F with Clara installed), Z plays 1.5 seconds either side of the crossfade, X plays the left item up to the center and C plays from the center of the right item. Hold Ctrl or Shift with the key for a longer, 3 second version. See Keyboard Modes.

Note

The mouse-hover audition keys, A and Shift+A (which plays at the custom audition rate), find the folder and position from the mouse pointer, so they are not available from the keyboard. A keyboard version is planned.
