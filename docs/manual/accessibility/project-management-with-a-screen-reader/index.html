Project Management with a Screen Reader

This chapter covers the housekeeping around a production: statistics, notes, folders and backups.

Statistics

Press F1 to open the accessible Show Statistics window. It lists the album length and the number of CD markers, the project age, session time, total project length, source material length, number of items, folders, tracks per folder, special tracks and regions, the number of destination S-D edits and item splits, and the FX and automation lane counts. The first entry reads out the ReaClassical and REAPER versions and the name of this computer as your license knows it. Step through the values with ↑ and ↓; you can reset the session timer from the window. See Statistics.

Notes, Names and Ranks

  • N opens the accessible Notes window with fields for the project note, the track note, and for the selected item its name, rank, take number and item note. ← and → (or Q and W) move between items while it is open, and Space plays and stops
  • Shift+N opens the quick Item Name window
  • Ctrl+R opens Item Rank

Folders and Items

  • Ctrl+D (Duplicate folder (No items)) adds a copy of the selected folder's tracks as a new folder, without its items. In a horizontal workflow it first asks whether to convert to a vertical workflow. It announces "Folder duplicated"
  • Shift+D deletes the selected source folder, and Ctrl+Alt+Shift+Delete deletes every item in every source folder. Both are for the vertical workflow and ask you to confirm. "No source items found" is announced if there is nothing to delete
  • Ctrl+Alt+A selects all items in the folder of the selected track. If no track is selected, or the track is not in a ReaClassical folder, you are told
  • Ctrl+V pastes items and announces how many were pasted

Backups, Cleaning and Archiving

Backups, cleaning and archiving are REAPER features that work as described in Project Management. ReaClassical sets auto-save to every 15 minutes. Use REAPER's own File menu for Clean current project directory and Save project as.

Project Tabs

Ctrl+Alt+N opens a new project tab and Ctrl+Tab moves to the next one, announcing its name. Use separate projects or tabs for the discs of a multi-disc album.
