Navigating a Project with a Screen Reader

Every move through a ReaClassical project can be made from the keyboard and is announced, so you always know where you are. Mouse navigation also still works as in any REAPER project.

Tracks and Folders

↓ and ↑ select the next and previous track in the current folder and announce its name, its peak level and any mute or solo state. In a project with a single track per folder they move between folders instead. Alt+↓ and Alt+↑ move to the next and previous folder, and D goes to the first folder. Moving to a folder makes it the folder you hear (the others are muted), un-arms any record-armed tracks, selects the item nearest the edit cursor and announces the folder.

If a special track such as an aux, submix or reference is selected, ↓ and ↑ step through the visible special tracks and announce each one with its peak and mute or solo state. At the ends you hear "At bottom of folder", "At bottom of project" or "Last special track".

To go straight to a track, press Shift+J and type part of its name.

Items, Fades and Markers

  • ← and → (or Q and W) move to the previous and next item or fade and announce it as, for example, "Mozart take 3". While editing a crossfade they move through the crossfade, and with an envelope selected they move between its points
  • Alt+← and Alt+→ go to the start and end of the selected item
  • Ctrl+Shift+← and Ctrl+Shift+→ go to the first and last item on the track
  • Shift+Q and Shift+W go to the start and end of the folder
  • Alt+Q and Alt+W go to the previous and next group of crossfaded items
  • , and . go to the previous and next marker

Markers, Regions and Time Selection

These actions are silent in REAPER itself; ReaClassical speaks the result of each one.

  • M adds a marker at the cursor and announces its position. Alt+M inserts or edits a marker, which is how you give it a name
  • Ctrl+M deletes the marker nearest the cursor and says which one. Ctrl+Shift+M moves the nearest marker to the cursor and says which one moved and where. Ctrl+Shift+G deletes all generic markers ("All generic markers deleted")
  • ; creates a region from each selected item, named after the active take ("3 regions created"), and Ctrl+Alt+R deletes all regions ("All regions deleted"). : creates a region from the time selection and L opens the region and marker manager
  • [ and ] set the start and end of the time selection at the cursor and announce its position and, once both edges are set, its length in plain words. Ctrl+] and Ctrl+[ move the cursor to the start and end of the time selection and announce the position ("No time selection" if there is none). / sets the time selection to the selected items
  • 0 deselects all items

Project Tabs

Ctrl+Alt+N opens a new project tab ("New tab") and Ctrl+Tab or NumPad + switches to the next one, announcing the name of the project you land on. See Multi-Project Tab S-D Editing.

Jumping to a Time or a Take

  • J jumps to a time in the project. Type digits that are read from the right, as HH:MM:SS:FF, so 100524 is 10 minutes 5 seconds 24 frames. Start with + or - to move relative to the cursor
  • Ctrl+J does the same within the selected item or a set of crossfaded items
  • Enter searches for a take by number using the file name of the media item. See Finding Takes

Announcements

These speak without moving anything:

Shortcut Announces
T Current take number
Shift+T Highest take number
Alt+F Items in the current folder
Ctrl+Shift+J Timeline position
Alt+Shift+J Time within the current item
Alt+P RCMASTER peak level
! The last announcement again

While recording, the take number is on Alt+A instead of T. In Mixer Mode, I announces the input of the current track and Enter announces its status.

Showing and Hiding Children

Select a parent track and press E to show or hide its child tracks, so that editing a multi-microphone folder is as simple as editing a stereo track.
