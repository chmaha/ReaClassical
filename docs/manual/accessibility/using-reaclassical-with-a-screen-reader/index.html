Using ReaClassical with a Screen Reader

ReaClassical is designed so that a blind or low-vision engineer can carry out a complete classical production, from creating a project through recording, editing, mixing, mastering and rendering, using only the keyboard and a screen reader. This section explains how that works. Each workflow chapter also contains short, purple Screen reader users notes wherever the keyboard-driven path differs from the standard one.

How This Section Is Organized

This section is meant to be a complete guide to ReaClassical for blind and low-vision engineers. Read Getting Started with a Screen Reader first, then follow the production through the chapters that mirror the workflow chapters elsewhere in the manual. Keyboard Modes and The Terminal are reference chapters for the modal keyboard controls and the command box.

Clara

Clara is the accessibility bridge that lets ReaClassical speak through your screen reader. It is a REAPER extension available for Windows and macOS. When Clara is installed:

  • ReaClassical announces what it is doing (for example, the take number, the timeline position, the result of an edit) instead of relying on something you must see on screen
  • Windows that are mouse-driven for sighted users, such as Mission Control, Notes, Preferences and the DDP Metadata Editor, open as keyboard-driven accessible windows instead
  • Where a window offers many options, pressing H inside it opens a list of that window's shortcuts that you can step through one at a time with the Up and Down arrows

To install Clara, open the Terminal (Ctrl+Enter) and type clara. See The Terminal. Clara is installed into your ReaClassical folder and REAPER restarts to load it.

Accessible Windows and Standard Windows

Every accessible window has a standard (ReaImGui) counterpart for sighted collaborators. Press Ctrl+Alt+Shift+G (Toggle GUI Mode) to switch between them. Any Mission Control, Notes, Preferences, Mixer Snapshots or DDP Metadata Editor window that is open notices the change and reopens in the other mode. This only applies while Clara is installed; without it, the standard windows are always used.

Announcements

ReaClassical provides quick announcements that you can trigger at any time:

Shortcut Announces
T Current take number
Shift+T Highest take number
Ctrl+Shift+J Timeline position
Alt+Shift+J Time within the current item
Alt+F Items in the current folder
Alt+P RCMASTER peak level
! Repeats the last announcement

The Mixer Mode window (Alt+S) lets you move through mixer tracks and hear their input and status.

Keyboard-Driven Windows

Shortcut Window
Ctrl+Alt+Shift+R Recording Settings: session name, take number, schedule, overlapping and horizontal takes, clip reporting
Ctrl+Alt+Shift+F9 Close Recording Session (stops the Record Panel Daemon)
Ctrl+R Item Rank, with note-taking and item navigation
Shift+N Item Name
V Item Edit Mode
Alt+S Mixer Mode
Ctrl+Alt+Shift+G Toggle between accessible and standard windows

Other accessible windows include Create Project, Track Setup, Smart Import, Distribute Takes, Fix Crossfade Sequence Edits, Automation Navigator, Edit Automation, Mixer Track Grouping, Snapshot Settings, Playback Rate, Peak and Overs Check, Audio Calculator, Show Statistics and Preferences. With Clara installed they replace the standard windows of the same name; see the Keyboard Shortcuts reference for their keys.

Keyboard Modes

For tasks that need many keys, ReaClassical has keyboard modes: Crossfade Mode (F), Item Edit Mode (V), Mixer Mode (Alt+S) and an automatic Recording mode. Ctrl+Alt+Shift+E always returns you to the normal keys. See Keyboard Modes.

Not Using a Screen Reader?

The accessible windows are built for screen reader users, and if you can see the screen you will normally prefer the graphical windows. The keyboard shortcuts, however, are a very fast way for anyone to work. If you want to experiment without Clara installed, the Terminal command debug=on prints announcements to the REAPER console and turns the accessible windows on for the current project.
