What's New in ReaClassical 27

ReaClassical 27 is the biggest release so far. The headline is complete screen reader support, but sighted engineers get a great deal too:

  • One-click rendering from the DDP Metadata Editor to DDP, Cue Audio, WAV, FLAC, Opus, MP3 and mixer stems
  • Import DDP and PMI masters to rebuild a CD layout for checking or remastering
  • A CD Player with Transition Review, and a Peak and Overs Check for the whole project
  • Quick Export Recorded Takes to hand takes to musicians or the producer from the session
  • A far more flexible Smart Import, with polywav splitting, take filtering and folder distribution options
  • Safer editing: S-D edits automatically remove sliver edits and shorten crossfades when source material runs short
  • A new default theme, a tidier menu and background recall of mixer snapshots

This page is a short tour. Everything here is covered in detail in the relevant chapter, linked below.

If you are updating from ReaClassical 26, see Update.

New Functions

Working with a screen reader

ReaClassical can now be used from start to finish by a blind or low-vision engineer, with no mouse. Several parts of this are handy for sighted users too.

  • Clara, a REAPER extension for Windows and macOS, lets ReaClassical speak through your screen reader. Install it by typing clara in the Terminal
  • Accessible windows replace the mouse-driven ones (Create Project, Track Setup, Smart Import, Preferences, Notes, DDP Metadata Editor, Mixer Snapshots and more). Sighted collaborators can switch any of them back with Toggle GUI Mode (Ctrl+Alt+Shift+G)
  • Announcements for take number, timeline position, items in a folder, RCMASTER peak and more, with ! to repeat the last one
  • Menu Help (Ctrl+Alt+Shift+H) reads out the ReaClassical menu with the shortcut for each item
  • Marker safety: with Clara installed, placing a source or destination IN marker after the existing OUT marker deletes that OUT marker and tells you, instead of leaving a broken pair
  • Keyboard modes let you finish a whole task with single keys: Crossfade Mode (F) to slip, nudge, widen, narrow and shape a crossfade, Item Edit Mode (V) for one item's fades, edges and gain, and Mixer Mode (Alt+S) to mute, solo, pan, flip polarity and set faders without touching track selection. Ctrl+Alt+Shift+E always returns you to the normal keys
  • The Terminal (Ctrl+Enter): type a command such as 1m;2m;3s to mute tracks 1 and 2 and solo track 3. It also installs Clara (clara), sets nudge amounts and converts workflows. The reaper command updates REAPER itself to the version ReaClassical has been tested with (reaper=latest for the newest release, reaper=752 for a specific one). The Terminal works for everyone, with or without Clara. Type help for the full command guide

See Using ReaClassical with a Screen Reader, Keyboard Modes and The Terminal. Every workflow chapter also has short purple Screen reader users notes.

Note

You do not need a screen reader to benefit from the new keyboard-driven tools below. Without Clara installed, ReaClassical behaves as it always has.

Importing

  • Import DDP (Ctrl+Alt+Shift+D) rebuilds the CD track and album metadata layout from an existing DDP image, for checking or remastering
  • Import PMI (Ctrl+Alt+Shift+M) does the same from a Pyramix pre-master
  • Polywav import in Smart Import splits a multi-channel file from a portable recorder into mono and stereo tracks using a simple pattern (for example 221: two stereo pairs, then mono). It replaces the old ExplodeMultiChannel function

See Importing.

Recording and monitoring

  • Quick Export Recorded Takes (Ctrl+Shift+D) renders every take so far to WAV, FLAC, Opus or MP3, ready to hand to the producer or musicians on location
  • Toggle Monitor (Ctrl+Shift+A) cycles input monitoring across the input tracks: off, on, tape mode
  • Playback track: a new special track that sends the RCMASTER mix to its own pair of hardware outputs. Toggle it with Ctrl+Alt+Shift+P
  • Disarm All Tracks removes every record arm in one step
  • Take Number Display (Alt+T) shows the current take number in a small window so a colleague can follow along

See Recording.

Rendering

The DDP Metadata Editor (Y) now has a row of Render buttons. Each renders straight away, without REAPER's render dialog, into an Exports subfolder:

  • DDP (Red Book settings) and Cue Audio
  • WAV, FLAC, Opus 160 and MP3 320, one file per CD track, with album and track metadata and cover.jpg/cover.png cover art embedded where the format allows
  • M: Stems, one WAV per mixer track for each CD track
  • Custom, which opens REAPER's render dialog pre-filled with your choices

Sample rate, bit depth and dither are set with dropdowns, and a Tracks box (for example 1-3,5) limits which CD tracks are rendered. Before rendering, ReaClassical also warns about text that DDP and CD-Text cannot hold, duplicated ISRC codes and tracks without a title.

See Rendering.

Mixing

  • Panic Mute (Alt+K) instantly silences everything that can reach your hardware
  • Toggle RCMASTER Hardware Output Mute (Ctrl+Alt+Shift+T) mutes or unmutes all of RCMASTER's hardware sends together

See Mixing.

Mastering

  • CD Player (Ctrl+Alt+Shift+Y) plays the album back like a physical CD player, including a Transition Review that plays only the joins between tracks
  • Peak and Overs Check (Shift+P) scans the whole project through the faders and routing up to RCMASTER, reports the highest peak and lists every over above a threshold you choose, each with a Go to button

See Mastering.

Editing and navigation

  • Fix Crossfade Sequence Edits (Shift+X) repairs items that have drifted out of alignment across the tracks of a folder, for example after ripple-per-track was accidentally switched off
  • Auto-color project (Shift+K) colors items by take number or folder
  • Auditioning around S-D markers from the keyboard: 6 to 9 (with Ctrl and Alt variants) play short segments around the source and destination markers
  • Folder and track navigation: move to the next or previous folder or track in a folder, jump to the first or last item on a track, move to the start or end of the selected item, and step between crossfade groups
  • Nudging of markers (Ctrl+,, Ctrl+.) and selected items (Alt+,, Alt+.) by a project nudge amount, with larger "x modifier" versions
  • Jump to Time is now split into jumps within the project and within the selected item (J and Ctrl+J)

See Editing and Navigating a Project.

Project management

  • Delete Source Folder (Shift+D) and Delete All Source Items (Ctrl+Alt+Shift+Delete) clear out source material in a vertical workflow
  • Support Info To Clipboard (Shift+F1) copies your ReaClassical and REAPER versions, ready to paste into a forum post (without the SWS extension it shows them in a message box to copy by hand)

See Project Management.

New default theme

ReaClassical 27 ships with a redesigned theme as the default: a graphite look with an accent color and redrawn toolbar and transport icons and panels. The Light and two WaveColors (Dark and Light) variants have all been redesigned to match, and the ReaClassical 26 themes are still included if you prefer them.

Improvements and Fixes

Importing

  • Smart Import can now be run on a project that already contains material. New takes are inserted at the edit cursor and only the material that needs to move is moved (26 always added to the end)
  • Import only these takes restricts an import to a session name and/or a list such as 1-3,5,11-15
  • In a vertical workflow, choose the starting folder and a distribution mode: one folder per take, use current folder count, or round-robin across a custom number of folders. A preview shows the result

Editing

  • Every S-D edit, 3-point edit, timestretched insert and delete now removes sliver edits left near the markers, and shortens a crossfade when there is not enough source material for the full length. You are told when either happens

Mixing and automation

  • Mixer Snapshots has a Background auto-recall option, so snapshots keep recalling after you close the window
  • Insert Automation (I) works on a time selection, can stay open for several adjustments in a row, and switches on automation mode automatically (source folders locked, ripple on all tracks). Toggle it yourself with Shift+I
  • New shortcuts to show and hide automation lanes (Alt+D, Alt+E), move between automation items (Shift+←, Shift+→) and envelope lanes (Ctrl+Shift+↑, Ctrl+Shift+↓), and edit an automation item (Ctrl+I)

Project setup and management

  • Mission Control can add the Playback track, move aux and submix tracks left and right in the mixer, and run Auto-color
  • Convert REAPER project now auto-colors the converted project instead of running Prepare Takes
  • Remove Take Names always works on the first folder, so no track needs to be selected first
  • Create Project needs only one track per folder (it was two)
  • Show Statistics (F1) now includes session time with a reset button and your ReaClassical and REAPER versions, and can copy everything to the clipboard
  • Help (H) opens the single-page HTML manual installed with ReaClassical. The PDF manual is gone

A tidier menu

The ReaClassical menu has been reorganized to follow the production from start to finish.

  • Project Setup is now Project Management, and gathers Mission Control, Preferences, conversion, imports and folder tools in one place
  • Auditioning is split into Mouse Hover and Keyboard sections
  • Show Children and Hide Children are combined into a single Hide/Show Child tracks toggle
  • Prepare Takes has been retired. Editing functions find what they need on their own

Shortcuts that changed

If you are used to ReaClassical 26, these existing actions have a new key.

Action 26 27
Record Panel Ctrl+Enter Alt+Enter (Ctrl+Enter now opens the Terminal)
Jump to Time Tab J
Edit Automation Ctrl+Alt+Shift+A Ctrl+I
Add marker and edit Ctrl+M Alt+M
Hide / Show Children E / D E (one toggle)
Prepare Takes T retired
Auto Solo Folder Ctrl+Alt+Shift+S no default key (Ctrl+Alt+Shift+S is now Snapshot Add)

The complete current list is in the Shortcuts Guide.

Under the hood

  • The scripts have been reorganized: the actions you use are in the main ReaClassical folder, while supporting code lives in a lib subfolder and the crossfade editor helpers in crossfade_editor.
  • ReaClassical 27 bundles REAPER 7.78 (26 shipped 7.52)
  • New bundled JSFX: RCModulator (adds gentle movement to a static reverb tail) and the airwindows ports MagicFairyDust2 and Oxide and Seek. RCTimePhase has a fix for high-frequency loss in its interpolation
  • A new Shortcuts Guide and Terminal Command Guide are installed with ReaClassical and open in your browser

Fixes in the 27.0.x releases

  • Smart Import now handles polywav files correctly (27.0.3)
  • Peaks are no longer missing after a polywav import (27.0.5)
  • Auto Solo Folder has moved into the lib subfolder, in line with the other supporting scripts (27.0.5)
  • Polywav import is available in the accessible Smart Import (27.0.4)

For the complete list of changes in every release, see the Changelog.
