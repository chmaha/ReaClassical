Keyboard Shortcuts

When providing keyboard shortcuts, this manual assumes Windows or Linux as the operating system when modifier keys are used. MacOS users should use the typical standard substitutions. If in doubt, open up the actions menu via keyboard shortcut ? or explore the top "ReaClassical" menu to see the current assignments. For reference (from REAPER's own user guide), here is a table of equivalent modifier keys:

PC (Windows or Linux) Key Mac (MacOS) Key Equivalent
Shift Shift
Control (Ctrl) Command (Cmd)
Alt Option
Windows Control

The best way of becoming familiar with ReaClassical keyboard shortcuts is to hover over buttons in Mission Control C and the S-D editing toolbar F6, but most of all, explore the top "ReaClassical" menu inbetween "Options" and "Extensions".

Other Keys

Besides ReaClassical's own functions, the ReaClassical keymap assigns keys to a handful of REAPER and SWS actions:

Keys Action
O / P / R REAPER Preferences / Project Settings / Render dialog
Ctrl+F9 Pause
Ctrl+- / Ctrl+= Rewind / fast forward a little
Ctrl+_ / Ctrl++ Move the cursor one pixel left / right
Ctrl+↑ / Ctrl+↓ Increase / decrease the peaks display zoom
Ctrl+P Clear all peak indicators
Alt+M Insert and/or edit a marker at the current position
: / ; Insert a region from the time selection / from the selected items (named by the active take)
/ Set the time selection to the selected items
0 Deselect all items
L Region and marker manager
Ctrl+E View envelopes for the current or last touched track
Ctrl+Shift+N Move the edit cursor to the next envelope point and select it
Alt+Shift+E or Ctrl+Shift+E Add or edit the envelope point value at the cursor
Tab Move the cursor to the item's peak sample (SWS)
Alt+Shift+H Trim or untrim the item's left edge to the edit cursor (SWS/Xenakios)
NumPad + Switch to the next project tab
Shift+B Batch file converter

The Shortcuts Guide

A complete, searchable list of every ReaClassical shortcut is available as a web page, generated from the keymap that ships with ReaClassical so it is always accurate. Open it offline from the ReaClassical menu with Shortcuts Guide, or online at https://reaclassical.com/rcshortcuts.html. Type in the search box to filter by action name, mode or key.

The Mode column matters. "Normal" shortcuts work everywhere. The other values are keyboard modes with their own keys: Crossfade Mode, Item Edit Mode, Mixer Mode and Recording mode (see Keyboard Modes), and the two-lane crossfade editor's own shortcuts. The same key can mean something different in each mode.

Screen reader users (Clara)

Ctrl+Alt+Shift+H (Menu Help) walks through the ReaClassical menu with a screen reader, announcing the shortcut for each item, so you can explore the available functions without leaving REAPER.
