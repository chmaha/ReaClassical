Edit Types

The S-D Edit action makes an edit from whichever of the four markers you have set. The more markers you set, the more control you have; the ones you leave out are worked out for you.

4-point edit

Set all four markers. The source passage replaces the destination passage. If the two are different lengths, the material after the edit moves earlier or later (ripples) to fit. This is the most precise kind of edit and the one to reach for when you know exactly what you are replacing.

3-point edit

Set any three markers. ReaEdit works out the fourth from the length of the pair you did set:

  • Destination IN, source IN and source OUT: the source passage is placed at destination IN, and the destination OUT is calculated from the source length
  • Destination IN, destination OUT and source IN: the source OUT is calculated from the destination length
  • and so on for the other combinations

Three-point editing is the everyday way to work: you say where it starts, what to use, and for how long.

2-point edit

Set one destination marker and one source marker. ReaEdit fills in the missing ends from the ends of your material:

  • Destination IN and source IN: from those points to the end of the source material and to the end of the project
  • Destination OUT and source OUT: from the start of the material and of the project up to those points
  • Source IN and destination OUT: from source IN to the end of the source, and from the start of the project to the destination OUT
  • Source OUT and destination IN: from the start of the source to source OUT, and from destination IN to the end of the project

Two-point edits are useful for quickly joining the start or end of one take to another.

Assembly line (3-point insert)

3-point Insert Edit builds a performance from consecutive pieces without replacing anything. Set destination IN, source IN and source OUT; the action inserts the source passage at destination IN and pushes everything after it later. When it has finished, it places a new destination IN at the end of the piece it just inserted, so the next piece follows straight on: set a new source IN and OUT and run the action again. Destination OUT is not needed, because it is worked out from the length of the source passage.

ReaEdit remembers the item it just inserted. If you have moved destination IN away from the end of that item since the last assembly-line edit, it asks:

  • Yes starts a new edit sequence at the marker where you put it
  • No moves destination IN back to the edge of the last item, so you can continue the sequence
  • Cancel does nothing

4-point edit with time-stretching

Insert with timestretching needs all four markers (with fewer, nothing happens). It fits the source passage to the destination passage by stretching or shrinking it, which is handy for matching a short drop or a tempo difference. Use it sparingly: a large change will be audible. If there is no material between the source markers you will see "Please make sure there is material to copy between your source markers."

Crossfades, undo and what you will be told

Every edit puts a crossfade at each join, with a length set in Preferences. The whole edit is a single undo step. If ReaEdit had to shorten a crossfade because there was not enough source material, it tells you; with OSARA installed it speaks it, without OSARA it shows a message.
