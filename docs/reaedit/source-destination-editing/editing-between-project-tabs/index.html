Editing Between Project Tabs

Source-destination editing can span two open project tabs: the source material in one, the performance you are assembling in the other. This is useful for keeping each take, or each movement, in its own project.

Project markers

Two extra markers say which tab is which:

Marker Name Action
Destination project DEST PROJECT Set Dest Project Marker
Source project SOURCE PROJECT Set Source Project Marker

Place each at the edit cursor in its tab. The position does not matter; the beginning or the very end of the timeline is a good place to keep them out of the way. Like the other markers there is only ever one of each.

Working across tabs

  1. Set DEST PROJECT in the destination tab and SOURCE PROJECT in the source tab.
  2. Place the destination markers in the destination tab and the source markers in the source tab, as usual.
  3. Run S-D Edit (or any of the other edit actions).

The one rule is that source markers must be paired with a source project marker, and destination markers with a destination project marker. Your markers stay in place in both tabs after an edit, which makes it quick to undo in the destination tab and apply the same edit again.

If you have set only one project marker you will see "Only one S-D project marker was found. Use zero for regular single project S-D editing or use two for multi-tab S-D editing." If markers and project markers do not match, you will be told they should be paired.

Remove the project markers with Delete S-D Project Markers when you have finished.
