Markers

ReaEdit marks an edit with four markers. They are ordinary REAPER project markers, named and coloured by ReaEdit, so they show on the ruler and in the Region/Marker Manager like any other.

Marker Name Colour Action
Destination IN DEST-IN cyan Add Destination IN marker
Destination OUT DEST-OUT cyan Add Destination OUT Marker
Source IN SOURCE-IN green Add Source IN marker
Source OUT SOURCE-OUT green Add Source OUT marker

Destination is where the new material goes; source is where it comes from. IN is the start of a passage and OUT is its end.

Placing markers

Each marker action puts its marker at the edit cursor, or at the play position if REAPER is playing, so you can place markers on the fly while listening. There is only ever one marker of each kind: placing a new SOURCE-IN removes the old one, in every open project tab. Each placement is its own undo step.

After an edit

The markers you placed stay where they are, so you can see what was done, and you can undo and run the edit again with adjusted markers. If you set fewer than four markers, the missing ones that ReaEdit worked out for the edit (see Edit Types) are removed again once the edit is made, so they never get in your way.

Removing markers

Delete All S-D markers removes the four markers from every open project. Delete S-D Project Markers removes the two project-tab markers (see Editing Between Project Tabs). Both are a single undo step.

Marker numbers

ReaEdit identifies its markers by their numbers (996 to 1001) as well as their names, so avoid using those numbers for markers of your own.
