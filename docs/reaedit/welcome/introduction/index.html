Introduction

ReaEdit is a free set of source-destination (S-D) editing tools for REAPER. Source-destination editing is the technique classical music engineers use to build a finished performance from many takes: you mark the passage you want to take (the source) and the place it should go (the destination), and one action makes the edit, with a crossfade at each join. It is how dedicated classical editing systems work, and ReaEdit brings it to an ordinary REAPER installation.

ReaEdit is a small part of ReaClassical, the complete classical production system built on REAPER (recording, editing, mixing, mastering and rendering). It is made from the same S-D editing scripts, and it is yours to use free of charge for as long as you like. It needs no license key and no account.

What you get:

  • Source and destination IN and OUT markers, placed at the edit cursor
  • The S-D edit itself: 2-, 3- and 4-point edits from whichever markers you have set, with automatic crossfades
  • The assembly-line (3-point insert) edit for building a take from consecutive pieces
  • A 4-point edit that time-stretches the source to fit the destination
  • Delete with ripple, and delete leaving silence
  • Editing between two open project tabs
  • One key to open REAPER's crossfade editor, or, for screen reader users, a keyboard-driven crossfade mode
  • Spoken feedback through OSARA, which is essential if you use a screen reader

What you need:

  • REAPER, plus ReaPack to install and update ReaEdit (or the zip download, which does not need ReaPack)
  • No SWS, no ReaImGui, no other extensions
  • If you are blind or low-vision, OSARA: it is what makes ReaEdit speak (the Accessibility FAQ explains how to install it)

Where to start

New to source-destination editing? Read Your First Edit next. Already comfortable with it? Skim Markers and Edit Types, then set up your keyboard shortcuts.

ReaEdit does not assign any keyboard shortcuts for you, and it does not change how REAPER looks or behaves apart from the actions it adds. Everything here works in your existing REAPER setup.
