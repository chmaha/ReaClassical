Installation

ReaEdit is installed into an existing REAPER setup. There are two ways to get it. The recommended one is ReaPack, which registers the actions for you and keeps ReaEdit up to date.

Installing with ReaPack (recommended)

ReaEdit has its own ReaPack repository, separate from ReaClassical's.

  1. Install ReaPack in REAPER if you do not have it yet.
  2. Choose Extensions > ReaPack > Import repositories..., paste https://raw.githubusercontent.com/chmaha/ReaClassical/main/ReaEdit/index.xml and press OK.
  3. Choose Extensions > ReaPack > Browse packages..., search for ReaEdit, right-click the package and choose Install, then press OK to apply.
  4. Open the Action List (Actions > Show action list...) and search for ReaEdit to find the actions.

To update later, choose Extensions > ReaPack > Synchronize packages. ReaEdit is versioned separately from ReaClassical, starting at 1.0.

Only the actions you use

ReaPack adds just the 17 actions you use directly to your Action List. The keyboard crossfade mode is made of about 45 more small actions; they are installed, but they are not added to your Action List unless you set up the crossfade mode, which is only for OSARA users. If you do not use a screen reader you will never see them.

Installing from a zip (without ReaPack)

  1. Download ReaEdit.zip.
  2. Unzip it into REAPER's Scripts folder (Options > Show REAPER resource path in explorer/finder, then open Scripts). This creates a ReaEdit folder; keep all of its files together.
  3. In REAPER open the Action List, choose New action > Load ReaScript... and select Register ReaEdit actions.lua from the ReaEdit folder. Run it once: it adds every ReaEdit action to the Action List, and running it again is harmless.
  4. Search the Action List for ReaEdit and bind the shortcuts you want.

A zip install is not updated automatically. To update, download the newest zip, unzip it over the old ReaEdit folder (allow it to overwrite) and run Register ReaEdit actions.lua again.

Removing ReaEdit

With ReaPack, find ReaEdit in Browse packages, right-click it and choose Uninstall. With the zip, delete the ReaEdit folder and remove the leftover entries from the Action List.

Compatibility

ReaEdit is tested with the version of REAPER that ships with ReaClassical (7.78 at the time of writing). Other recent versions are expected to work, but that is the one it is tested against. It needs no extensions: no SWS, no ReaImGui. If you are blind or low-vision, you should also install OSARA: it is what makes ReaEdit speak, and ReaEdit is built to be used with it.

Using ReaClassical too?

ReaEdit is for people who want S-D editing in their own REAPER. If you use ReaClassical, you already have these functions, with many more, so you do not need ReaEdit. Do not install ReaEdit into your ReaClassical instance. Keep ReaEdit for a separate, ordinary REAPER.
