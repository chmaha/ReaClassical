Crossfade Mode (Keyboard)

ReaEdit includes a keyboard-driven crossfade mode. It gives you the same control over a crossfade as REAPER's two-lane crossfade editor, but entirely from the keyboard, with every action spoken. It is designed for screen reader users, and it needs OSARA to be installed, because OSARA is what speaks. If you work visually, you do not need it: use REAPER's own crossfade editor.

Why it exists

REAPER's own crossfade editor is visual: you read the waveforms and drag them with the mouse. At the moment it is not fully accessible with a screen reader, so ReaEdit includes its own keyboard version, with full parity with the visual editor in the features classical music engineers use: moving the crossfade and the audio inside it, widening and narrowing it, shaping the fades, listening to each side, and putting everything back. It is driven entirely from the keyboard and every action is spoken, so you never need to see the window.

REAPER's editor has a few further features that are not part of the keyboard mode: view options, which do not apply without sight, phase alignment, which classical editing does not call for, and presets.

With and without OSARA

The same action starts both. With OSARA installed it starts crossfade mode. Without OSARA it opens REAPER's own visual crossfade editor instead, as described in REAPER's Crossfade Editor.

Setting it up

You do this once.

  1. Bind a key to the Crossfade Editor action. Open the Action List (Actions > Show action list...), search for ReaEdit_Crossfade Editor and give it a shortcut. ReaEdit does not choose this key for you, so use whichever suits you; F is a suggestion, and it is what ReaClassical uses.
  2. Create the key file. The first time you use that key with OSARA running, ReaEdit tells you the crossfade mode keys are not installed yet and offers to create them. Choose Yes. It adds the crossfade mode's actions to your Action List, which ReaPack does not do for you, writes a file called ReaEdit Crossfade Mode.ReaperKeyMap into REAPER's KeyMaps folder, and tells you where it is.
  3. Import the file. In the Action List choose Import/export, then Import shortcuts/custom actions, import all sections..., and open the file.

That is all. If you choose No at the prompt, crossfade mode starts anyway and you are asked again next time until the keys are installed; choose Cancel to do nothing for now.

ReaEdit uses the last alternate keyboard section, Main (alt-16)

The crossfade mode keys are set in REAPER's last alternate keyboard section, Main (alt-16), and importing the key file sets shortcuts in that section. Very few people use it, but if you have set up shortcuts of your own there, please back them up first. In the Action List choose the section Main (alt-16), then Import/export, then Export shortcuts/custom actions for this section only..., and save the file somewhere safe. Importing the key file may replace shortcuts you already have on the same keys. It does not change your main keymap or any other section.

The keys only exist while crossfade mode is on. REAPER switches to that section when the mode starts and switches back from it when it ends, so they never touch your normal shortcuts and nothing you have bound in the main section changes. While the mode is on, REAPER's own standard shortcuts are switched off as well, so a stray key press cannot trigger something unexpected (such as deleting the selected items).

Using it

  1. Select the right-hand item of a crossfade. Or use the actions Navigate to Next Crossfade and Navigate to Previous Crossfade, which jump to a crossfade, select its right-hand item and say which one it is, for example "Crossfade 2 of 5 at 19 seconds, 950 milliseconds, take 3 to take 4, 100 milliseconds". You can bind keys to them (Alt+W and Alt+Q are suggested).
  2. Press the key you bound to Crossfade Editor. You hear "Crossfade mode on". ReaEdit selects both items of the crossfade and their matching items on every track, puts the edit cursor at the centre of the crossfade, and switches on ripple per track for as long as the mode is on.
  3. Use the keys below. Every action says what it did.
  4. Press Esc to leave. Inside the mode Esc always leaves it, whichever key you used to start it. You hear "Crossfade mode off", and your ripple setting is put back as it was.

If nothing is selected you hear "No items selected", and if the selected item is not the right-hand item of a crossfade you hear "No crossfade to the left of this item". The mode does not start.

Which side you are working on

Most actions work on the selected side of the crossfade: the left item, the right item, or both. You start with both selected. Choose with S (left), D (right) and A (both), and press Alt+A to hear which side is selected and the names of the items.

A few actions need a single side and tell you if both are selected: slipping, nudging and changing an item's volume. Where an action behaves differently for the left item, the right item and both, the key table above says what it does to the selected side.

Step sizes

Slipping, nudging, shifting, widening, narrowing and changing the fades all move by the same amount, 5 milliseconds to begin with. The "larger step" version of the same key moves by 5 times that. Change both in ReaEdit's Preferences: XFM nudge (ms) and XFM x modifier multiplier.

The keys

Choosing what to work on

A Select both items of the crossfade

Tips

  • Audition before you judge. Z plays either side of the crossfade, and X and C let you hear the left and right items on their own.
  • Change one thing at a time and listen. If a change makes it worse, Revert (Ctrl+Alt+0) puts the crossfade back as it was when you first changed it, however many steps ago that was.
  • When a move would use up too much of a neighbouring item, the action refuses and says why ("Cannot slip: right item's post-fade content too short"). Nothing has changed when you hear that.
  • Everything works on all your tracks together, as ReaEdit's edits do, so the tracks stay in step.
  • Undo works as normal. Each action is a single undo step.

If it does not work

  • The keys do nothing. The key file has not been imported. See Setting it up. If you chose No at the prompt, use the Crossfade Editor key again and choose Yes, then import the file.
  • The crossfade editor opens instead of crossfade mode. OSARA was not detected. Check that it is installed and loaded; the Accessibility FAQ links to its official installation instructions.
  • "No crossfade to the left of this item". Select the right-hand item of the crossfade.
