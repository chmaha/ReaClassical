Screen Readers

ReaEdit is built to be used with OSARA, the free accessibility extension for REAPER, and if you are blind or low-vision you should install it (see the Accessibility FAQ for how). OSARA is what makes ReaEdit speak the result of every action, and the keyboard crossfade mode needs it. If you work visually you do not need OSARA at all: ReaEdit works fully without it, shows messages in ordinary dialogs where it needs to say something, and the Crossfade Editor action opens REAPER's own visual crossfade editor.

What is spoken

  • Marker actions announce what they placed and where, for example "Added source out @ 1 minute 23 seconds"
  • S-D Edit and the other edits announce "S-D edit complete", and tell you if a crossfade was shortened or slivers were removed
  • Delete All S-D markers and Delete S-D Project Markers confirm what they removed
  • Warnings that would otherwise appear in a dialog are spoken instead, so you are not interrupted

Marker order checks

When OSARA is installed, ReaEdit also guards against placing a marker on the wrong side of its partner. If you place destination IN after the existing destination OUT, it deletes the stale destination OUT and says so; if you try to place source OUT before the existing source IN, it tells you "Source out must be after source in." and does not place it. This means an edit can never silently take far more material than you intended. Without OSARA these checks are not made.

A suggested way to work

  1. Bind the marker actions to keys you can reach without looking (see Keyboard Shortcuts).
  2. Navigate to a point with REAPER's normal navigation and listen to where you are.
  3. Place the marker and listen for the confirmation.
  4. Make the edit and listen across the join.

Crossfades

REAPER's crossfade editor is visual, and at the moment it is not fully accessible with a screen reader, so ReaEdit includes its own keyboard-driven crossfade mode for use with OSARA. It has full parity with the visual editor in the features classical music engineers use (slipping, nudging, shifting, widening and narrowing the crossfade, shaping the fades, auditioning each side and reverting), driven entirely from the keyboard, and it speaks everything it does. It needs one-time setup, described in that chapter.

Beyond ReaEdit

ReaEdit covers source-destination editing and crossfades. ReaClassical provides a full accessibility experience across the board: it is designed so that a blind or low-vision engineer can carry out a complete classical production, from creating a project through recording, importing, editing, mixing, mastering and rendering, using only the keyboard and a screen reader. It does this with its own screen reader bridge, Clara (for Windows and macOS), accessible windows, keyboard modes and a Terminal. See Using ReaClassical with a Screen Reader in the ReaClassical manual.
