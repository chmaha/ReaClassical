Accessibility FAQ

OSARA and your screen reader

Do I need OSARA?
If you are blind or low-vision, yes: OSARA is what makes ReaEdit speak, and the keyboard crossfade mode only starts when OSARA is installed. If you work visually you do not need it, and there is no reason to install it: the markers, edits and deletes work fully without it, messages appear in ordinary dialogs, and the Crossfade Editor action opens REAPER's own visual crossfade editor, which suits you better.
How do I install OSARA?
OSARA is a free accessibility extension for REAPER, installed separately from ReaEdit. Download it, and follow its installation instructions, from the official OSARA website. The REAPER accessibility wiki has more guidance on setting up REAPER with a screen reader, and OSARA's own project page is on GitHub. Restart REAPER after installing. ReaEdit finds OSARA by itself: to check, select the right-hand item of a crossfade and run the Crossfade Editor action. If you hear "Crossfade mode on", OSARA is working with ReaEdit.
I use ReaClassical. Do I need OSARA?
No. ReaClassical has its own screen reader bridge, Clara, which speaks everything ReaClassical does and takes the place of OSARA in a ReaClassical install (installing Clara removes any OSARA plugin, and it is installed with a single Terminal command). See Using ReaClassical with a Screen Reader in the ReaClassical manual. ReaEdit is for people who use REAPER without ReaClassical, and OSARA is what makes it speak there.
What does ReaClassical add for blind and low-vision engineers?
A full accessibility experience across the whole production. ReaClassical is designed so that you can carry out a complete classical production, from creating a project through recording, importing, editing, mixing, mastering and rendering, using only the keyboard and a screen reader. ReaEdit gives you the source-destination editing and the crossfade mode; ReaClassical adds accessible versions of its windows, keyboard modes for crossfades, items and the mixer, a Terminal, and guides for every stage of the workflow. See Using ReaClassical with a Screen Reader in the ReaClassical manual.

The keyboard crossfade mode

Why does ReaEdit have its own crossfade mode?
REAPER's own crossfade editor is visual, and at the moment it is not fully accessible with a screen reader. The keyboard crossfade mode has full parity with the visual editor in the features classical music engineers use, is driven entirely from the keyboard, and speaks every step. See Crossfade Mode (Keyboard).
The crossfade mode keys do nothing.
The key file has not been imported yet. See Crossfade Mode (Keyboard).
Will the crossfade mode change my shortcuts?
Only in one place. ReaEdit puts the crossfade mode keys in REAPER's last alternate keyboard section, Main (alt-16), and nowhere else: your main keymap and the other sections are not touched. Very few people use alt-16, but if you have shortcuts of your own there, back them up before importing the key file, because the import may replace shortcuts on the same keys. The Crossfade Mode (Keyboard) chapter shows how to export that section first.
The crossfade editor opens instead of crossfade mode.
OSARA was not detected. Check that it is installed and loaded, and see How do I install OSARA? above.

Crossfade mode messages

"No items selected" or "No crossfade to the left of this item"
Crossfade mode starts from the right-hand item of a crossfade. Select it, or use Navigate to Next Crossfade, and try again. See Crossfade Mode (Keyboard).
"Select left or right item first"
The action needs one side. Press S for the left item or D for the right item.
"Slip requires single item selected"
Slipping works on one item at a time. Choose a side with S or D.
"Cannot slip", "Cannot nudge", "Cannot narrow" or "Cannot shrink", followed by a reason
The move would use up too much of a neighbouring item, so ReaEdit refused and nothing changed. Use a smaller step, or move something else first.
"No next crossfade", "No previous crossfade" or "No crossfades on this track"
You are at the last or first crossfade, or the track has none.
"No crossfade context"
Crossfade mode has lost track of which crossfade it was on, usually because the items were changed outside the mode. Leave the mode and start it again.
