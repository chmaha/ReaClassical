Action Reference

The ReaEdit actions you use directly, as they appear in the Action List (search for ReaEdit). In the list each name begins with "Script: ".

Markers

Action What it does
ReaEdit_Add Destination IN marker Places DEST-IN at the edit cursor (or play position)
ReaEdit_Add Destination OUT Marker Places DEST-OUT
ReaEdit_Add Source IN marker Places SOURCE-IN
ReaEdit_Add Source OUT marker Places SOURCE-OUT
ReaEdit_Set Dest Project Marker Places DEST PROJECT for editing between tabs
ReaEdit_Set Source Project Marker Places SOURCE PROJECT for editing between tabs
ReaEdit_Delete All S-D markers Removes the four S-D markers from every open project
ReaEdit_Delete S-D Project Markers Removes the two project-tab markers

Edits

Action What it does
ReaEdit_S-D Edit The 2-, 3- or 4-point source-destination edit, with crossfades
ReaEdit_3-point Insert Edit Assembly-line insert: source passage inserted at destination IN
ReaEdit_Insert with timestretching 4-point edit with the source stretched to fit the destination

Deleting

Action What it does
ReaEdit_Delete With Ripple Removes the source passage and closes the gap with a crossfade
ReaEdit_Delete Leaving Silence Removes the source passage and leaves the gap

Crossfades

Action What it does
ReaEdit_Crossfade Editor Opens REAPER's crossfade editor, or with OSARA starts or leaves the keyboard crossfade mode
ReaEdit_Navigate to Next Crossfade Goes to the next crossfade, selects its right-hand item and says which one it is
ReaEdit_Navigate to Previous Crossfade The same, going backwards
ReaEdit_XFM ... The 45 actions that make up the keyboard crossfade mode. ReaPack installs them but does not list them in the Action List; setting up the crossfade mode keys adds them (OSARA users only). They are bound for you and only work inside the mode: see Crossfade Mode (Keyboard)

Settings

Action What it does
ReaEdit_Preferences The S-D crossfade length (ms, default 35), and for the crossfade mode the nudge (ms, default 5) and the larger-step multiplier (default 5)
