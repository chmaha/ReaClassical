Troubleshooting and FAQ

Messages and what they mean

"Please add at least 2 valid source-destination markers"
S-D Edit needs at least one destination marker and one source marker. See Edit Types.
"Please add 3 valid source-destination markers: DEST-IN, SOURCE-IN and SOURCE-OUT"
3-point Insert Edit needs exactly those three markers.
"Please use SOURCE-IN and SOURCE-OUT markers"
The delete actions take their range from the source markers. See Deleting.
"Please make sure there is material to copy between your source markers"
The source range is empty, or contains no items. Check the source markers and that the tracks have material there.
"Only one S-D project marker was found"
Use no project markers for editing in a single project, or two (one in each tab) for editing between tabs. See Editing Between Project Tabs.
"Source or destination markers should be paired with the corresponding source or destination project marker"
In a cross-tab edit, the source markers must be in the tab with the source project marker and the destination markers in the tab with the destination project marker.
"The DEST-IN marker has been moved since the last assembly line edit"
You moved destination IN after the previous assembly-line insert. Answer Yes to start a new sequence, No to put the marker back at the previous item's edge.
"Crossfade shortened to N ms ... due to limited source material"
There was not enough source material for a full crossfade at that join. Move the marker further into the take if you want the full length.

Frequently asked questions

Questions about OSARA, screen readers and the keyboard crossfade mode are in the Accessibility FAQ.

I installed ReaEdit but see no actions.
Search the Action List for ReaEdit. If you installed from the zip, you must run Register ReaEdit actions.lua once. If you used ReaPack, run Extensions > ReaPack > Synchronize packages and check ReaEdit is installed in Browse packages.
How is this different from ReaClassical?

ReaEdit is only the source-destination editing part of ReaClassical, for people who want it in their own REAPER. ReaClassical takes a classical production from start to finish:

  • An easy Create Project workflow, with a choice of horizontal or vertical workflow approaches, and project management through a dedicated Mission Control window
  • Robust zero-collision recording with the Record Panel: automatic take numbering, session naming, rankings and notes, scheduled recording and more
  • Smart importing
  • Editing: everything in ReaEdit, plus healing edits, finding takes, source auditioning, automatic crossfade protection, razor editing and many more functions
  • Mixing with a unique approach to automation: mixer snapshot scenes (faders, pan, mute, solo, FX, sends and routing) that are recalled automatically during playback and converted to real automation before rendering. Everyday automation is just as easy: select a passage, set the level and optional ramps in and out, and ReaClassical creates the automation for you, with no need to add automation points by hand
  • Mastering that is unique in the DAW world: all your album and CD-Text metadata in one window, with the CUE file, CD-Text and HTML album report updating automatically, a DDP image a click away, and no need to keep album markers and items in sync by hand
  • Quick rendering from the metadata editor: one click to WAV, FLAC, Opus, MP3 or a DDP image, without REAPER's render dialog

In all, ReaClassical has nearly 300 actions.

Because ReaClassical already includes all of ReaEdit's functions, if you use ReaClassical you do not need ReaEdit. If you use a screen reader, ReaClassical has its own screen reader bridge, Clara, so OSARA is not needed with ReaClassical (see the Accessibility FAQ). See reaclassical.com.

I love ReaEdit! How do I move up to ReaClassical?

ReaClassical is free and open source, so there is nothing to buy. See reaclassical.com for what it includes.

  1. Install it. Run the ReaClassical installer for your system. It creates a separate, self-contained ReaClassical folder with its own REAPER, so your existing REAPER and ReaEdit are left untouched. ReaClassical cannot be installed into an existing REAPER. See Installation in the ReaClassical manual.
  2. Keep your keys. ReaClassical's marker and edit keys are the ones this manual suggests (1 to 4 for the markers, 5 for the S-D edit), so your hands already know them.
  3. Bring your work across. A ReaEdit project is an ordinary REAPER project, and ReaClassical can convert an existing one. See Converting a Standard REAPER Project.

Do not install ReaEdit into your ReaClassical instance: it already has all of these functions, and many more.

Do I need a licence or an account?
No. ReaEdit is free to use.
Does it work with my existing projects?
Yes. It works on any project; there is nothing to convert. A project edited with ReaEdit is an ordinary REAPER project that opens in any REAPER, whether or not ReaEdit is installed.
Why did the edit change all my tracks?
ReaEdit treats the tracks of a project as parallel channels of one recording and edits them together. Keep material that should not be edited together in a separate project.
