Keyboard Shortcuts

ReaEdit does not assign keyboard shortcuts, so that it can never clash with your own. Because you will place markers and make edits constantly, set up keys before you start serious work.

Binding a key

  1. Open the Action List (Actions > Show action list...).
  2. Search for ReaEdit and select an action.
  3. Click Add... under Shortcuts for selected action, press the key you want and confirm. REAPER warns you if the key is already used.

Suggested keys

These are the keys ReaClassical uses, so they will feel familiar if you move between the two. Check REAPER's conflict warning for each one.

Action Suggested key
Add Destination IN marker 1
Add Destination OUT Marker 2
Add Source IN marker 3
Add Source OUT marker 4
S-D Edit 5
3-point Insert Edit F3
Insert with timestretching F4
Delete With Ripple Backspace
Delete Leaving Silence Ctrl+Backspace
Delete All S-D markers Ctrl+Delete
Set Dest Project Marker Ctrl+Alt+1 (or Ctrl+Alt+2)
Set Source Project Marker Ctrl+Alt+3 (or Ctrl+Alt+4)
Delete S-D Project Markers Shift+Delete
Preferences F5
Crossfade Editor F
Navigate to Next Crossfade Alt+W
Navigate to Previous Crossfade Alt+Q

The Crossfade Editor action opens REAPER's crossfade editor, or with OSARA starts the keyboard crossfade mode. The crossfade mode's own keys are separate: they are set up for you and only work while the mode is on, so you do not bind them yourself.

The first four sit under one hand on the number row and read left to right the way an edit is described: destination in and out, then source in and out. Pick whatever suits you; the actions do not care.

Mouse and toolbar

You can also put the actions on a REAPER toolbar or in a menu through REAPER's own customisation, or run them from the Action List.
